# 1. Mirror 6x6 dice table
exact: 32 kept cells, 4 rejected; codes used: 32 distinct, each exactly 1 time(s)
=> for a fair die every kept cell has probability 1/36, so each 5-bit code has probability exactly 1/32 given acceptance (bijection).
mirror property verified: (a,b) and (b,a) share the first 4 bits and differ in the 5th bit, for all 15 unordered pairs.

# 4. Card knockout
exact: all 4! orders of 4 distinct cards -> 8 patterns of 3 bits, each exactly 3 times
exact: all 8! orders of 8 distinct cards -> 128 patterns of 7 bits, each exactly 315 times
=> each group gives exactly uniform bits; disjoint groups of a uniformly shuffled deck have independent uniform relative orders,
   so all 45 bits of a deck (6 octets + 1 quad) are independent and fair. (Proof in design-notes.md; Monte Carlo below.)
